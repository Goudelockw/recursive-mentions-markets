Risk model

The risk model flags favorites (50–98¢) that have lost more often than their price says. Each marker earns an avoid point only in the price ranges where it cost 4+ extra losses per 100, in both periods, on 30+ markets. Enough points make a favorite AVOID. Fading an AVOID favorite is TRADE+ (1.5× stake); buying one is skipped. It is a rule set, not a fitted model, so it isn't refit weekly; each release records which rule set it was reviewed with (43 rules now, id 455043d364c7).
